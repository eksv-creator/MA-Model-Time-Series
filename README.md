# Модель скользящего среднего (MA) для временного ряда

## О проекте
Учебный проект по построению и диагностике модели MA(q) для временного ряда финансовых показателей.

Цель: подобрать порядок модели, оценить её параметры и проверить адекватность через анализ остатков.

## Данные
Временной ряд цен акций. Ряд предварительно проверен на стационарность (ADF-тест), при необходимости взята первая разность.

## Использованные методы и технологии
- **Язык:** Python
- **Библиотеки:** pandas, numpy, statsmodels, scipy, matplotlib
- **Методы:**
  - ADF-тест на стационарность (встроенный и ручной)
  - Ручная ACF с доверительными границами
  - Подбор порядка q по AIC
  - Оценка MA(q) через `statsmodels` и вручную через MLE (минимизация отрицательного лог-правдоподобия)
  - Диагностика остатков: Ljung-Box, тест Энгла (ARCH), тест Уайта, Jarque-Bera
  - Сравнение с адаптивными методами (SES Брауна, Хольт)

## Что сделано
- Проверка стационарности ряда
- Ручное вычисление ACF и определение значимых лагов
- Подбор оптимального порядка q по AIC
- Оценка параметров модели двумя способами
- Полная диагностика остатков
- Адаптивный прогноз на 10 шагов и сравнение с SES и Хольтом

## Результаты
- Подобран оптимальный порядок MA(q) по AIC
- Проверена адекватность модели через Ljung-Box (остатки не коррелированы)
- Проведено сравнение с альтернативными методами прогнозирования
